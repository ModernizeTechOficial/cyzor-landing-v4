# CYZOR V4 — Card Visual System

## Status
OFFICIAL — single visual reference for all landing cards.

## Purpose
Define one reusable card language before production HTML and final composition.

## Card families
- Standard
- Highlight
- Module
- Metric / State
- Product Evidence
- Action

## Visual contract
- Base surface: deep graphite / near-black.
- Border: thin, precise, low-contrast.
- Active/selected signal: CYZOR lime #C8FF00 used selectively.
- Radius: 14–16px.
- Padding: 20–28px.
- Primary typography: Inter.
- Technical metadata: DM Mono.
- Depth comes from surface separation, border, restrained lighting and controlled glow; not heavy shadows.
- No generic glassmorphism.
- No decorative gradient on every card.
- Cards must feel like one operating system.

## State behavior
Default: graphite surface + neutral border.
Hover: small luminance/elevation response + restrained signal.
Selected: explicit lime indicator/border.
Active: state marker plus accessible text/icon.
Disabled: reduced contrast while retaining structural boundaries.

## Composition rule
Cards support the narrative; they do not become a wall of repeated UI.
The same visual system must work across module, benefit, process, product and decision surfaces.

## Accessibility
Do not communicate state by color alone. Focus states must be visible. Text remains HTML.
