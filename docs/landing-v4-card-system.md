# CYZOR V4 — Card Visual System

## Purpose
Define one reusable visual language for all landing cards before HTML implementation.

## Card family
1. Standard
2. Highlight
3. Module
4. Metric/state
5. Product evidence
6. Action

## Visual contract
- surface: deep graphite over black background
- border: thin, precise, low-contrast neutral line
- active border: restrained CYZOR lime
- radius: 14–16px
- padding: 20–28px
- typography: Inter
- metadata: DM Mono
- lime reserved for state, signal, selected and action
- no heavy glassmorphism
- no oversized shadows
- no decorative gradients inside every card
- cards must feel like one product system

## States
Default: graphite surface + neutral border.
Hover: slight elevation/brightness + subtle lime signal.
Selected: lime border/indicator.
Disabled: reduced contrast without removing structure.
Active: explicit state marker, not color alone.

## Usage
The card system is reused across modules, process steps, product evidence and decision surfaces. It must not turn the page into a repeated card grid.
