# CYZOR V4 — Art Direction

Status: VALIDATED

## Visual thesis

**CYZOR is a neural operating system rendered as a living technological environment.**

The page should feel like entering an intelligent infrastructure rather than browsing a conventional marketing website.

Core visual equation:

**SYSTEM + NEURAL NETWORK + PREMIUM SOFTWARE + SPATIAL DEPTH + LIME SIGNAL**

## Material language

Primary environment:
- near-black graphite
- low-reflective dark surfaces
- subtle structural borders
- controlled atmospheric depth

Secondary materials:
- translucent technical planes
- fine-line network structures
- high-resolution product surfaces
- restrained lime illumination

Avoid glossy gaming materials.

## Lighting

Lighting is functional.

Lime illumination indicates:
- active node
- data transmission
- intelligence
- focus
- CTA
- system state

White/gray illumination indicates:
- structure
- hierarchy
- information
- inactive infrastructure

No rainbow lighting.

No dominant blue or purple.

## Neural visual language

Use:
- nodes
- paths
- orbital relationships
- signal traces
- intelligence hubs
- grids
- layered planes
- telemetry
- controlled particles

A neural element must communicate a relationship, state or flow.

## Signature visual devices

### 01 Neural Core
Primary intelligence/system focal point.

### 02 System Map
Large spatial diagram showing CYZOR relationships.

### 03 Signal Trace
A lime path showing information moving through a system.

### 04 Intelligence Hub
A visually concentrated node representing the AI Manager.

### 05 Product Fragment
Authentic interface evidence embedded inside the atmospheric system.

### 06 Technical Annotation
Small mono labels used sparingly to establish system precision.

## Composition

Use a 12-column desktop grid as a structural baseline.

Major compositions:
- asymmetric hero
- full-width system stage
- large visual + narrow text rail
- diagram-led architecture
- network-led AI section
- product-led evidence section
- focused decision surface
- cinematic CTA

Do not repeat the same composition in every section.

## Scale

Use deliberate scale contrast:

micro:
telemetry, labels, nodes

medium:
module elements, interface fragments

large:
Neural Core, network, product surface

very large:
section-level system compositions

## Typography

Display/body:
Inter.

Technical metadata:
DM Mono.

Typography should be clean and restrained. Avoid oversized editorial typography that becomes the primary visual identity.

## Color budget

Dominant:
dark graphite / black.

Secondary:
white / desaturated gray.

Accent:
#C8FF00.

Lime should appear primarily around meaningful active states.

## Image treatment

Generated assets should feel like members of one visual family.

Requirements:
- coherent lighting
- coherent material language
- same dark environment
- same lime energy
- no embedded marketing copy
- clean edges for isolated assets
- enough negative space for HTML overlays

## Background

The background is infrastructure, not wallpaper.

Layers:
1. black/graphite base
2. low-opacity structural grid
3. localized atmospheric light
4. sparse neural particles
5. signal paths
6. section-specific visual layers

Background density must change between sections.

## Motion language

Motion is engineered.

Use:
- pulse
- trace
- connect
- propagate
- reveal
- synchronize
- activate

Do not use:
- bounce
- elastic overshoot
- random floating
- constant particle storms
- gratuitous parallax

Respect prefers-reduced-motion.

## Product visualization

Abstract visuals establish the concept.

Product UI proves the concept.

The landing must therefore transition from:
**abstract system → architecture → intelligence → real product → decision.**

## Responsive art direction

Desktop:
spatial and cinematic.

Tablet:
fewer peripheral nodes, tighter system maps, preserved focal points.

Mobile:
sequential neural story, larger readable nodes, simplified relationships, no tiny network diagrams.

## Premium gate

Every section must work at three distances:

Far:
silhouette, scale, contrast.

Mid:
narrative, hierarchy, relationship.

Near:
typography, spacing, borders, labels, states.

If a section depends on glow or color to feel interesting, its composition must be strengthened.

## Anti-generic gate

The landing must not resemble:
- template SaaS
- AI startup landing
- crypto site
- gaming site
- generic dashboard

Distinctiveness must come from composition and system language, not decoration.
