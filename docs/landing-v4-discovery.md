# CYZOR V4 — Discovery

## Product
CYZOR is a modular business operating platform connecting operational modules, organizational context, data and AI capabilities in one system.

## Core model
Organization → Modules → Data → Context → Specialized Agents → CYZOR AI Manager → Intelligence → Decision → Action.

## Product domains
CRM, ERP, Projects, People, Docs, BI, Automations, Finance, Products, Stock, POS and Agenda.

## AI model
The AI Workforce is hierarchical. Specialized module agents understand their domain and report to a global CYZOR AI Manager. The manager consolidates context rather than presenting isolated chatbot experiences.

## Landing objective
The landing must make the visitor understand:
1. CYZOR is an operating layer for the company, not another isolated tool.
2. Modules are connected instead of being a collection of unrelated products.
3. AI works with operational context.
4. The product turns connected data into intelligence and actions.
5. The interface is a real software product.

## Narrative
The page should move from:
Identity → System → Intelligence → Product → Decision → Activation.

## Visual proof required
- a strong hero visual;
- a system architecture visual;
- specialized-agent visual;
- module ecosystem visual;
- data/context/intelligence flow;
- credible product interface;
- infrastructure/security visual;
- final activation visual.

These are future visual placeholders in the wireframe, not assets yet.

## HTML vs assets
HTML owns:
- navigation;
- headings;
- paragraphs;
- CTAs;
- labels;
- cards;
- semantic structure;
- important product information.

Assets own:
- complex visual objects;
- neural/system illustrations;
- interface fragments where useful;
- atmospheric visual elements.

## Content constraints
Do not invent customers, testimonials, revenue, performance numbers, certifications, security guarantees or adoption metrics.

## UX principles
- strong visual hierarchy;
- short copy;
- clear CTA;
- product evidence before generic claims;
- progressive narrative;
- mobile recomposition rather than desktop shrinking.

## Anti-patterns
No poster composition, no single giant AI illustration, no generic SaaS feature grid, no excessive cards, no decorative sci-fi without semantic purpose.

## Success criterion
A visitor should understand what CYZOR is, how its modules and AI relate, and what the product looks/feels like without needing to read a long marketing page.
