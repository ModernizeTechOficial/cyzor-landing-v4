# CYZOR V4 — Wireframe

Status: VALIDATED

## Experience model

The page is a continuous journey through a living neural operating system.

Desktop composition uses spatial asymmetry, large system visuals and changing section rhythms. Mobile recomposes each stage into a vertical sequence rather than shrinking desktop.

---

## 01 — NAVIGATION

**Purpose:** establish CYZOR identity and provide persistent orientation.

**Position:** fixed/top navigation over the dark system environment.

**Layout:**
- left: CYZOR brand
- center/right: compact navigation anchors
- right: primary activation CTA
- subtle system-state indicator

**Visual:** restrained, transparent dark surface with structural border.

**Motion:** navigation gains stronger surface separation after scroll.

---

## 02 — HERO / NEURAL CORE

**Purpose:** immediate recognition of CYZOR as a neural operating system.

**Composition:** spatial asymmetric hero.

- text occupies one side
- Neural Core dominates the opposing visual field
- peripheral system nodes cross the composition
- telemetry and signal traces establish scale
- CTA cluster stays close to the narrative

**Headline direction:**
Sua empresa opera como um sistema inteligente.

**Supporting direction:**
Dados, operações, pessoas e agentes de IA passam a operar no mesmo contexto.

**Visual hierarchy:**
1. Neural Core
2. headline
3. supporting copy
4. primary CTA
5. secondary CTA
6. telemetry

**Motion:** core pulse, signal propagation, subtle node activity.

**Mobile:** core becomes the visual anchor followed by copy and CTA; peripheral signals reduce.

---

## 03 — SYSTEM ACTIVATION

**Purpose:** transition from marketing narrative into system narrative.

A thin horizontal state sequence:

SYSTEM INITIALIZING
→ NETWORK ONLINE
→ AI WORKFORCE ACTIVE
→ CONTEXT SYNCHRONIZED

**Visual:** signal traces and state markers.

**Motion:** states activate sequentially as the section enters viewport.

---

## 06 — AI WORKFORCE

**Purpose:** explain specialized intelligence.

**Composition:**
- CYZOR AI Manager as central intelligence node
- specialized agents distributed around it
- each agent associated with a real business domain
- signal paths show context flowing toward the Manager and decisions flowing back

Agents:
CRM / ERP / PROJECTS / FINANCE / PEOPLE / BI

**Copy:** concise explanation of specialized agents reporting into unified context.

**Visual:** neural network, not chatbot UI.

---

**Composition:** ecosystem / constellation / layered architecture.

**Interaction:** selecting/hovering a module highlights its connections.

**Mobile:** preserve relationships but collapse the graph into a readable layered sequence.

---

## 08 — DATA → INTELLIGENCE

**Purpose:** explain CYZOR's core transformation.

Five-stage visual:

DATA
→ CONTEXT
→ INTELLIGENCE
→ DECISION
→ ACTION

**Composition:** horizontal data pipeline on desktop with depth and signal motion.

Each stage has a distinct semantic state.

**Motion:** signal travels through each stage when activated.

**Mobile:** vertical pipeline.

---

## 09 — PRODUCT INTERFACE / EVIDENCE

**Purpose:** prove CYZOR is real software.

**Composition:** large product interface stage surrounded by subtle system framing.

Show authentic product concepts/UI fragments where available.

Potential fragments:
- dashboard
- CRM
- products
- stock
- projects
- finance
- AI interaction

Do not fabricate metrics.

The product interface is the visual evidence center of the page.

---

## 10 — DECISION SURFACE

**Purpose:** demonstrate the operational result.

**Composition:** context and signals converge into a decision surface.

Visual sequence:

SIGNALS
+
CONTEXT
+
INTELLIGENCE
→ DECISION
→ ACTION

Use a strong asymmetrical decision card/surface, but avoid generic dashboard-card styling.

---

## 11 — SECURITY / INFRASTRUCTURE

**Purpose:** establish technical confidence.

**Composition:** layered infrastructure visual with protected paths, system boundaries and controlled signals.

Copy should describe principles rather than invent certifications or guarantees.

Keep the section visually quieter than the Hero and Decision sections.

---

## 12 — FINAL CTA

**Purpose:** close the system journey.

The visual language should suggest that the visitor has reached the complete operating system.

Composition:

SYSTEM COMPLETE
↓
ACTIVATE CYZOR

Strong Neural Core / system visual returns in a transformed final state.

Primary CTA dominates.

---

## 13 — FOOTER

Minimal technical footer.

Include:
- CYZOR
- navigation
- product areas
- legal links where applicable
- restrained technical metadata

No large visual competition with CTA.

---

# GLOBAL COMPOSITION

Desktop:
- 12-column base grid
- intentional asymmetry
- full-bleed system stages mixed with constrained content
- no repetitive section templates

Tablet:
- reduce peripheral network density
- preserve focal points
- maintain asymmetry where usable

Mobile:
- vertical narrative
- one focal visual at a time
- network relationships become sequential
- no microscopic diagrams
