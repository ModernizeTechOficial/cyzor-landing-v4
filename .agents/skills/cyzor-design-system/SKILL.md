# CYZOR Design System

Preserve the established CYZOR visual direction while enforcing shared patterns. Prefer existing tokens/components; avoid page-specific ad hoc CSS, overlapping cards and duplicated primitives.


## UI/UX authority

For new premium interfaces, landing pages, visual audits, motion, responsive
composition or major redesigns, use `.agents/skills/cyzor-ui-ux/SKILL.md`
as the higher-level design authority. This skill remains the compact reusable
component consistency layer.
