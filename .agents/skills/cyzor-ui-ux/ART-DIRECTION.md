# CYZOR ART DIRECTION — v2 Neural

## Purpose

This is the visual-taste layer above the component design system. It prevents
CYZOR from becoming a generic AI-generated SaaS interface.

## Core idea

CYZOR is operating infrastructure for organizations. Its visual language
combines futuristic systems design, engineered software, neural intelligence,
spatial computing language and controlled premium aesthetics.

## Signature visual devices

Use selectively:

1. System maps — modules connected to a central intelligence layer, data and
   decision flows.
2. Technical annotations — DM Mono labels, IDs, states, timestamps and system
   metadata.
3. Structural lines — dividers, grids, connection lines, framing and alignment.
4. Product fragments — real interface details, tables, command surfaces,
   AI responses and module relationships.
5. Neural depth — nodes, traces, signal paths, layered planes and controlled glow.
6. Scale contrast — oversized display type beside small technical metadata and
dense operational detail.

## Neural visual language

Use sci-fi as a technological operating language, never as entertainment.

Core devices:
- neural node networks
- signal traces and connection paths
- system cores and intelligence hubs
- telemetry / status readouts
- grid planes and scanlines
- layered interface planes
- controlled lime glow
- spatial depth without 3D gimmicks

The visual question is always: **what system relationship does this element explain?**

Avoid robots, spaceships, cyberpunk clichés, fantasy HUDs, excessive neon and
holographic decoration without product meaning.

## Composition

Default to a 12-column desktop grid, but do not make every section symmetrical.

Useful compositions:
- 7/5 split
- 8/4 split
- asymmetric editorial
- full-bleed dark system section
- product-led stage
- diagram-led section
- narrow text rail + wide visual field

Composition should change when the narrative changes.

## Visual rhythm

Alternate intentionally between:
- sparse
- dense
- explanatory
- visual
- dark
- light
- product
- conceptual

Do not create ten sections with identical spacing and card grids.

## Product visualization

Prioritize:

**organization → modules → data → workforce → AI manager → decision**

The visual should explain the product rather than merely decorate it.

## Image direction

Prefer architecture, systems, infrastructure, product details, contextual
technical scenes and restrained editorial imagery.

Avoid generic teams, random offices, AI robots, meaningless neon and unrelated
abstract gradients.

## Motion direction

Motion should feel engineered.

Good:
- reveal
- trace
- connect
- expand
- transition
- synchronize

Avoid:
- bounce
- wobble
- perpetual floating
- novelty effects

## Brand restraint

Lime is rare and intentional. Use it to indicate activation, intelligence,
focus, important state, connection or CTA emphasis.

Do not paint every border, icon and heading lime.

## Anti-template test

Remove the logo mentally.

If the page could be mistaken for a generic SaaS template, AI startup,
Web3 product or generic dashboard product, the art direction has not gone
far enough.

Change the composition or visual concept, not merely the color.

## Premium art-direction gate

A premium CYZOR composition should feel **engineered, futuristic and product-native**.
Judge it at three distances:

### Far view
The silhouette, scale and contrast should be recognizable before text is read.

### Mid view
The section hierarchy, visual rhythm and product story should become obvious.

### Near view
Spacing, typography, borders, labels, states and interaction details must feel deliberate.

If only the near view looks polished, the composition is not finished.

### Signature-to-purpose rule
Every signature visual must have a semantic job:
- orbit = system relationships / central intelligence
- trace = data-to-decision flow
- matrix = modular infrastructure
- operational surface = product evidence
- technical annotation = system precision

Do not reuse a signature simply because it looked good in another section.

### Composition tension
Prefer one meaningful tension per major section:
- large type / dense data
- dark system / illuminated intelligence
- dense neural graph / quiet interface plane
- sparse statement / operational detail
- central manager / distributed agents
- static structure / subtle motion

Avoid simultaneous tension everywhere; contrast loses meaning when everything competes.

### Premium anti-slop test
Remove color, shadows and animation mentally. If the section loses its identity,
its underlying composition is too weak. Rebuild the structure before styling it.
