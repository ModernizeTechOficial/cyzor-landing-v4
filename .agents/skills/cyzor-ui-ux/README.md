# CYZOR UI/UX Skill

This repository contains the CYZOR-specific premium UI/UX skill.

Use `.agents/skills/cyzor-ui-ux/SKILL.md` for:
- premium landing pages
- SaaS interfaces
- dashboards
- CRM/ERP
- AI/chat
- admin
- onboarding
- responsive design
- accessibility
- motion
- performance
- visual audits and polish

The skill is intentionally stronger than a generic design prompt: it anchors
the agent to the existing CYZOR visual foundation and enforces reusable,
production-oriented design decisions.

The skill is informed by public UI Skills patterns and principles from
frontend-design, landing-page design, typography/layout/color refinement,
motion, accessibility and production hardening.

It is not a verbatim copy of third-party skill files.
